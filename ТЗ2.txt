3. ТЕХНИЧЕСКИЙ СТЕК
============================================================
GUI-фреймворк: PySide6 (LGPL, pip install PySide6, wheel под Windows
без компиляции, без прав админа). Альтернатива, если PySide6 не встанет:
CustomTkinter (pip install customtkinter). Выбор между ними — за
пользователем, но по умолчанию PySide6 (лучше для многопоточности,
прогресс-баров и таблиц).

Дополнительные библиотеки:
- pyinstaller (опционально, для сборки .exe) — если пользователь захочет.
- qt-material или qdarktheme — тема оформления (опционально).

Стандартные:
- threading / QThread (для фоновых задач)
- json (для настроек)
- contextlib.redirect_stdout (для перехвата логов)

Принципы:
- Никаких субпроцессов. Модули импортируются напрямую.
- Никаких правок в src/. Всё — через monkey-patching в app/core/patches.py.

4. АРХИТЕКТУРА
============================================================
Слой 1 (не трогаем): src/*.py — существующая бизнес-логика.

Слой 2 (адаптер): app/core/patches.py
- Проблема: prepare_report.prepare_report() и transfer_dep.transfer_dep()
  внутри вызывают ask_choice() из своего модуля, а она использует input().
  В GUI input() заблокирует поток.
- Решение: перед вызовом функций — подменить ask_choice на GUI-версию
  через monkey-patching:
      import prepare_report
      import transfer_dep
      prepare_report.ask_choice = gui_ask_choice
      transfer_dep.ask_choice = gui_ask_choice
  где gui_ask_choice(prompt, options) открывает модальный диалог выбора
  и возвращает выбранное значение (в вызывающем потоке — см. раздел 6).
- Аналогично перехватить builtins.input на случай, если где-то останется
  прямой вызов. Вернуть дефолт (первый вариант) + записать в лог
  предупреждение.

Слой 3 (сервис): app/core/worker.py
- Класс Worker(QThread), который принимает callable + args/kwargs,
  выполняет в фоне, отдаёт сигналы: started, finished(result),
  failed(traceback), log(str).
- Перехват stdout/stderr внутри worker: подменять sys.stdout на объект,
  который пишет в сигнал log. Восстанавливать после.
- В GUI-потоке сигнал log обрабатывается и добавляется в QPlainTextEdit.

Слой 4 (UI): app/ui/*
- Главное окно с QTabWidget или боковым меню (5-6 экранов).
- Каждый экран — QWidget с формой (выбор файлов, параметры) + кнопка
  «Выполнить» + прогресс-бар + лог.
- Валидация полей до запуска (все ли файлы выбраны, есть ли файлы
  на диске, поддерживается ли расширение).
- После выполнения — кнопка «Открыть результат» (os.startfile).

6. РАБОТА С ДИАЛОГАМИ ask_choice (важно!)
============================================================
Существующие prepare_report и transfer_dep используют ask_choice() с
input(). В GUI это недопустимо. Решение:

6.1. Режим «предзаполнение» (основной):
- До запуска фоновой задачи GUI сам собирает все нужные параметры
  (файл, лист, КМ, DP) — через QComboBox, которые заполняются при
  выборе файла (см. экраны 5.3, 5.5).
- Затем в patches.py выставляется очередь предзаполненных ответов:
      _prefilled = [(prompt_pattern, answer), ...]
- gui_ask_choice(prompt, options):
      ищет в _prefilled подходящий ответ (по подстроке prompt);
      если находит — возвращает и логирует «Выбрано автоматически: X»;
      если нет — ставит задачу в GUI-поток (QMetaObject.invokeMethod
      с BlockingQueuedConnection), показывает модальный QDialog со
      списком options, ждёт ответа, возвращает.

6.2. Режим «спросить на лету» (запасной):
Если предзаполнения нет — открывается модальный диалог.
Реализуется через QMetaObject.invokeMethod(..., Qt.BlockingQueuedConnection)
из фонового потока в GUI-поток. Пример:
      class _AskBridge(QObject):
          result = Signal(object)
          @Slot(str, list)
          def ask(self, prompt, options): ...
- В фоновом потоке: bridge.result.wait(...), вернуть значение.

6.3. Если по какой-то причине диалог не может быть показан —
возвращать options[0] и писать в лог «⚠️ ask_choice вызван без GUI —
взят первый вариант».

7. ОБРАБОТКА ОШИБОК
============================================================
- Все исключения из фонового потока ловятся, выводятся в лог с полным
  traceback, плюс всплывает QMessageBox с кратким текстом и кнопкой
  «Показать детали» (открывает модальное окно с traceback).
- Специальные случаи:
  * PermissionError при попытке открыть/сохранить .xlsx — подсказка
    «Закройте файл в Excel и попробуйте снова».
  * UnicodeEncodeError — не должно случаться (перехват stdout), но
    если случится — логировать и продолжать.
  * FileNotFoundError, ValueError из парсера — показывать понятный
    русский текст + рекомендовать проверить PDF/xlsm.

9. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
============================================================
- Все длительные операции (парсинг PDF, чтение xlsb, сравнение) — в
  фоновом потоке. UI не должен «зависать».
- Перехват stdout: всё, что функции печатают через print(), попадает
  в лог-панель соответствующего экрана.
- Прогресс-бар на каждом экране; для операций без промежуточного
  прогресса (parse_pdf, compare) — indeterminate (setRange(0, 0)).
- Все подписи — на русском.
- Подсказки (setToolTip) на каждой кнопке и поле.
- Горячие клавиши: Ctrl+O — открыть файл, Ctrl+Enter — выполнить,
  Ctrl+Q — выход.
- Иконка приложения app/assets/icon.ico.
- Размер окна по умолчанию 1100x750, минимальный 900x600.
- Тёмная/светлая тема — переключение на лету.

10. ЗАПУСК
============================================================
- run_gui.bat в корне проекта:
      @echo off
      cd /d "%~dp0"
      python app\main_gui.py
      if errorlevel 1 pause
- app/main_gui.py:
      import sys
      from PySide6.QtWidgets import QApplication
      from ui.main_window import MainWindow
      from core.settings import load_settings

      def main():
          app = QApplication(sys.argv)
          s = load_settings()
          w = MainWindow(s)
          w.show()
          sys.exit(app.exec())

      if __name__ == "__main__":
          main()

- (Опционально) сборка в .exe через PyInstaller:
      pyinstaller --onefile --windowed --icon=app/assets/icon.ico ^
          --name "ExcelCompare" app/main_gui.py
  Если пользователь попросит — собрать. Без прав админа
  PyInstaller работает из user-директории.
